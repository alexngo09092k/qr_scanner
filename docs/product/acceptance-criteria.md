# Acceptance Criteria

## Scan
- [x] Mở tab Scan → camera khởi động (mobile_scanner)
- [x] Khung quét rõ ràng, animation scan line mượt
- [x] Bật/tắt đèn flash, chuyển camera trước/sau
- [x] Chọn ảnh từ thư viện → nhận diện QR/Barcode
- [x] Khi quét thành công: haptic + chuyển màn Result
- [x] Result: copy, share, mở link/phone/email/map theo loại

## Generate
- [x] Danh sách loại QR đẹp, có icon + màu riêng
- [x] Form nhập liệu validation rõ ràng
- [x] Preview QR realtime
- [x] Lưu vào History + Share / Copy trên Result

## History
- [x] Tab Tất cả / Quét / Tạo
- [x] Search theo nội dung
- [x] Swipe để xóa / long-press yêu thích
- [x] Tap mở lại Result

## Settings
- [x] Theme: System / Light / Dark
- [x] Rung khi quét thành công (on/off)
- [x] Xóa toàn bộ lịch sử (có confirm)
- [x] Phiên bản app

## UI/UX chung
- [x] Bottom navigation đẹp, animation chọn tab
- [x] Không crash khi từ chối quyền camera (màn PermissionDenied + retry)
- [x] Empty state có illustration + CTA
- [x] Dark mode contrast đạt chuẩn (Plus Jakarta Sans + palette custom)
